Impacto ONE

Política de Privacidade

Última atualização: agosto de 2026

1. Quem somos

A Impacto Soluções Empresariais LTDA desenvolve e opera o Impacto ONE, um aplicativo móvel que dá acesso, via celular, às rotinas comerciais do ERP Sankhya de cada empresa cliente — pedidos, clientes, produtos e indicadores. O Impacto ONE é uma ferramenta interna de uso corporativo, distribuída apenas para colaboradores autorizados das empresas contratantes, não um aplicativo de uso público.

2. Que dados coletamos

Os dados que o aplicativo acessa pertencem à empresa contratante e já existem no ambiente Sankhya dela — o Impacto ONE não cria uma base de dados paralela nem os compartilha com terceiros. Além disso, coletamos:

  • Dados de conta: e-mail e senha de acesso, usados apenas para autenticação no próprio aplicativo.
  • Localização: usada somente durante o uso ativo das funções de roteirização e check-in/check-out de visita, para registrar o trajeto e a presença no cliente visitado.
  • Fotos: foto de perfil (opcional) e fotos tiradas no check-in/check-out de visitas, quando o vendedor opta por anexá-las.
  • Áudio: gravações de voz enviadas voluntariamente pelo vendedor na função "Pedido por voz", processadas para transcrição e extração automática dos dados do pedido.
  • Notificações: um identificador técnico do aparelho (push token), usado só para envio de lembretes (agenda, liberação de pedido).
  • Dados de uso: registros técnicos de acesso e erros, para suporte e manutenção do serviço.

3. Como usamos esses dados

Os dados são usados exclusivamente para operar o aplicativo em nome da empresa contratante: autenticar o usuário, exibir e permitir a edição de informações comerciais já existentes no Sankhya, calcular rotas, transcrever pedidos por voz e enviar lembretes relevantes. Áudios de pedidos por voz são enviados a um serviço de terceiro (OpenAI) apenas para transcrição e interpretação automática do conteúdo, e não são usados para nenhuma outra finalidade.

4. Compartilhamento com terceiros

Não vendemos, alugamos nem compartilhamos dados pessoais com terceiros para fins de marketing. Dados só trafegam com prestadores estritamente necessários à operação do serviço (infraestrutura de servidor, serviço de transcrição de voz, envio de notificações push), sempre sob as finalidades descritas nesta política.

5. Armazenamento e segurança

Os dados de conta e configuração ficam armazenados em servidor próprio, protegido por autenticação e controle de acesso por perfil (vendedor, gerente, diretor). Uma parte dos dados (cadastros, pedidos, catálogo) permanece também em cache local no aparelho, para permitir uso sem conexão à internet, e é sincronizada automaticamente quando a conexão volta.

6. Seus direitos

Como usuário de uma ferramenta corporativa, o titular dos dados de negócio é a empresa contratante. Para solicitações relacionadas aos seus dados pessoais de acesso (e-mail cadastrado, foto de perfil, exclusão de conta), entre em contato pelo canal abaixo.

7. Contato

Dúvidas sobre esta política ou sobre o tratamento de dados no Impacto ONE podem ser enviadas para contato@impactosolucoes.com.
